## What's Changed

### New Features

- **Search a page's tabs from the command palette**: tabs such as Firewall › Port Forwards or Administration › SSH Access are now searchable; "firewall port" goes straight to Port Forwards.
- **Page content fades in** instead of crossfading the old and new pages over each other.

### Improvements

- Respects the system's reduced-motion setting across the sidebar, drawer, accordions, tooltips, palette and fades.
- Lighter stylesheets and less per-frame work when scrolling and collapsing the sidebar.

### Bug Fixes

- Fixed a blank strip opening between the sidebar rail and the content when collapsing or expanding it.
- Fixed the search box, shortcut hint and page content shifting while a page loads.
- Fixed dropdowns not being reachable with the keyboard after opening them with the arrow keys.
- Fixed table cells wrapping when a plugin sets its own table font size, e.g. mini-diskmanager's partition table.
- Fixed table labels being squeezed to one character per line next to long values, e.g. the Dockerman overview.
- Fixed unknown header indicators showing as solid black squares.
- Fixed top-level sidebar entries without children looking different from their neighbours and showing no active state.
