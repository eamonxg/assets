## What's Changed

### New Features

- **Backgrounds**: Set a wallpaper for both the login page and the main interface, tune it with live-preview sliders, and give the login card its own frosted-glass controls.
- **Asset Manager**: One place to upload and manage custom fonts and brand assets.
- **Redesigned Theme Store**: A reworked store with creator identity, sizes shown for bundled fonts, toolbar icons and backgrounds, and a "My Shares" page that explains itself.
- **Richer Sharing**: A shared theme now carries the font file itself, the icons its shortcuts point at, and its background settings — published straight from your browser, so a wallpaper never has to route through the router.
- **Whole-Theme Presets**: The five built-in presets are now complete themes rather than colour sets.
- **Asset Review**: The store now tells you when a shared asset is under review.

### Improvements

- The theme store paints instantly from cache instead of waiting on the hub.
- The store is now usable on a phone.
- Roughly half the frontend weight, so pages load faster on the router.
- Clearer page and tab names, plus loading and empty states that say what is actually happening.
- Translations refreshed across all fourteen languages.

### Bug Fixes

- Fixed built-in store cards rendering from a stale cache.
- Fixed applying a shared theme having no visible effect.
- Fixed switching themes leaving the previous theme's assets behind.
- Fixed unpublishing a share reporting a network error when the share was already gone.
- Fixed each page printing its name twice.
- Fixed the selected tick landing on the wrong card.
- Fixed the store search box taking up an empty row of its own.
- Fixed the content width setting applying to layouts that are not centred.
- Fixed untranslated fallback text inside translated sentences.
