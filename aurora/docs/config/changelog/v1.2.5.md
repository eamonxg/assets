## What's Changed

### New Features

- **Inbox**: a new Theme Marketplace tab for store notices and things that need your attention — a missing update source, shares that need updating, assets the reviewer turned down, and shares taken down.
- **Unread count in the header**: an inbox icon with the unread count on every LuCI page.

### Improvements

- The Studio toolbar is quieter: installed versions sit on one line, marked when an update is available with a link to the package manager; export, import and reset move into a "more" menu.
- The background picker states what it accepts (PNG · JPG · WebP · up to 8 MB), and WebP backgrounds can now be shared.
- A rejected share now shows the reviewer's note.

### Bug Fixes

- Fixed backgrounds that could be set on the router but then failed to share with a generic error.
- Fixed the inbox indicator showing as a solid square on themes that hide indicator text, such as shadcn.
- Fixed a stray line under the Studio toolbar.
